AI vs ML vs DL: Exam Notes

Definitions, differences, types, algorithms, deep learning basics, and ready-to-write answers.

1. The big picture

Every DL is ML. Every ML is AI. Not the other way round.

Not all AI learns: GPS shortest-path and old chess programs are AI built on rules and search, not ML.

Artificial Intelligence

Machines doing tasks that normally need human intelligence: reasoning, deciding, understanding language, recognising things.
e.g. Google Maps routes, chess engines, voice assistants

Machine Learning

A subset of AI where machines learn patterns from data instead of following rules written by humans.
e.g. spam filter, Netflix/YouTube recommendations

Deep Learning

A subset of ML that uses neural networks with many hidden layers to learn directly from raw data (images, audio, text).
e.g. face unlock, ChatGPT, Google Translate
Exam tip: Arthur Samuel (1959) described ML as giving computers the ability to learn without being explicitly programmed.

ML pipeline: collect data → clean data → choose model → train → test → deploy (use). Garbage in, garbage out: data quality matters more than a fancy model.

Training loop: predict → measure error (loss) → adjust weights → repeat.

Gradient descent: like walking downhill blindfolded; each step moves the weights in the direction that reduces loss. The learning rate is the step size: too big overshoots the minimum, too small is very slow.

UnderfittingGood fitOverfitting

Signs of overfitting: training loss keeps falling while validation loss rises. Data leakage = test data sneaking into training, which makes results look falsely good.

3. Three types of machine learning

TypeDataGoalExamples
SupervisedLabelled (input + correct answer)Predict the answer for new inputsSpam filter, house price, exam marks
UnsupervisedNo labelsFind groups / hidden patternsCustomer segments, fraud detection

Supervised has two kinds: Classification → output is a category (spam/not spam, cat/dog). Regression → output is a number (price, temperature, marks).

Reinforcement keywords: agent, environment, action, reward. RLHF (Reinforcement Learning from Human Feedback) is used to make chatbots like ChatGPT more helpful.

5. Deep learning basics

Artificial neuron: output = activation( w₁x₁ + w₂x₂ + … + b ). Inspired by brain neurons, but far simpler.

Worked example: inputs 0.5, 0.2, 0.9 · weights 0.8, −0.4, 0.6 → 0.40 − 0.08 + 0.54 = 0.86 → ReLU(0.86) = 0.86.

Activation functions: ReLU = max(0, x), fast, used in hidden layers. Sigmoid = 1/(1+e−x), squashes to 0–1. Without activations, the network can only learn straight-line (linear) relationships.

Why "deep"? Many hidden layers between input and output. Each layer learns more complex features: edges → shapes → parts → whole object.

Backpropagation: make a prediction (forward pass) → compute the error → send it backward through the layers → adjust each weight with gradient descent.

NetworkBest for
CNN (Convolutional)Images, video: filters slide over the image to detect patterns
RNN / LSTMSequences (older approach for text and speech)
TransformerLanguage: ChatGPT, Gemini, Claude. Uses attention to focus on relevant words
GAN / DiffusionGenerating images

How ChatGPT works (simply): a large Transformer trained to predict the next word (token), one at a time. GPT-3 has 175 billion parameters.

Limits of DL: needs huge data and GPUs, expensive, hard to explain (black box), and can produce confident but wrong answers (hallucinations). Verify important facts.

7. Ready-to-write answers

Q1 (2 marks). Define AI, ML and DL.AI is making machines perform tasks that need human intelligence. ML is a subset of AI where machines learn patterns from data without explicit rules. DL is a subset of ML that uses multi-layer neural networks to learn from raw data.
Q2 (2 marks). Differentiate classification and regression.Both are supervised learning. Classification predicts a category (e.g. spam / not spam); regression predicts a continuous number (e.g. house price).
Q3 (2 marks). What is overfitting?When a model memorises the training data, including noise, so it performs well on training data but poorly on new, unseen data. Reduced by more data, simpler models, regularisation, or ensembles like random forest.
Q4 (5 marks). Explain five differences between ML and DL.(1) Scope: DL is a subset of ML. (2) Data: DL needs far more data. (3) Features: ML relies on human-chosen features; DL learns features automatically. (4) Hardware: DL usually needs GPUs. (5) Explainability: ML models are easier to interpret; DL is a black box. Add one example each: spam filter (ML), face recognition (DL).
Q5 (5 marks). Explain the types of machine learning with examples.Supervised (labelled data; classification and regression; spam filter, price prediction). Unsupervised (unlabelled data; clustering such as K-Means; customer segmentation). Reinforcement (agent learns from rewards and penalties in an environment; game-playing AI, robots). Draw the summary table from Section 3.

Self-test

  1. ChatGPT belongs to AI, ML or DL? → DL (and therefore ML and AI)
  2. Netflix recommendations? → ML
  3. Grouping customers without labels? → Unsupervised (clustering)
  4. A robot learning to walk with rewards? → Reinforcement learning
  5. Which algorithm predicts a number like house price? → Linear regression
